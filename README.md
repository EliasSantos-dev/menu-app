# Menu App 🍽️

App web de **cardápio digital** para restaurantes, construído em **Next.js**. Catálogo de produtos com filtro por categoria, carrinho de compras e autenticação de usuário.

🔗 **Demo:** https://menu-app-sooty.vercel.app

## ✨ Funcionalidades

- Catálogo de produtos com **filtro por categoria**
- **Carrinho** de compras
- **Login** de usuário
- Layout responsivo de restaurante

## 🧱 Stack

- **Next.js** + **React** + **TypeScript**
- **Material UI** + **Emotion**
- **Redux Toolkit**
- **Supabase**
- **Framer Motion**

## 🚀 Rodando localmente

```bash
npm install
npm run dev
```
